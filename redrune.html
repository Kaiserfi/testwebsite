Play RedRune

Download the client, open it, and log in. It connects to the server on its own.

Download for Windows
Mac or Linux? Download RedRune.jar and open it with Java.
Android (test version)? Download RedRune.apk, open it and allow installing. The app updates itself after that.
Need help?
  1. RedRune needs Java 17 or newer. If it isn't installed, the client tells you and opens the free download at adoptium.net. Install the latest version, then open RedRune again.
  2. If Windows shows "Windows protected your PC", click More info then Run anyway. This appears for programs that aren't signed by a big publisher.
  3. The first start downloads the game files, which takes a minute. After that it opens straight away.
